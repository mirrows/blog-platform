## 1. 产品概述

### 1.1 产品定位
个人生活记录博客平台，面向普通读者，核心价值在于内容展示与分享。

### 1.2 产品目标
- 提供美观、流畅的阅读体验
- 支持文章发布、管理、展示全流程
- 构建读者互动社区（评论、点赞、收藏）
- 支持多语言、暗黑模式等个性化体验

### 1.3 目标用户
- **普通读者**：浏览文章、评论互动、搜索内容
- **注册用户**：除读者权限外，可点赞、收藏文章
- **管理员**：文章发布管理、评论审核、用户管理、文件管理、数据统计

## 3. 非功能需求

### 3.1 性能要求
- 首屏加载时间 < 2s（SSG优化后）
- API 响应时间 < 500ms
- 支持 1000+ 并发访问

### 3.2 安全要求
- JWT Token 鉴权
- 密码加密存储（bcrypt）
- 评论内容 XSS 过滤
- 文件上传类型/大小校验
- 接口速率限制

### 3.3 兼容性要求
- 支持 Chrome/Firefox/Edge/Safari 最新版本
- 响应式适配：移动端（≥320px）、平板（≥768px）、桌面（≥1024px）

## 4. 用户交互流程

### 4.1 访客浏览流程
```
首页 → 浏览文章列表 → 点击文章 → 阅读详情 → 评论（游客身份）
                                                     ↓
                                              填写昵称+内容 → 提交
```

### 4.2 用户注册登录流程
```
首页 → 点击登录/注册 → 填写信息 → 注册成功/登录成功 → 跳转首页
```

### 4.3 管理员后台流程
```
登录 → 进入后台 → 仪表盘
      ├── 文章管理（新建/编辑/删除/发布）
      ├── 分类管理（新增/编辑/删除）
      ├── 标签管理（新增/编辑/删除）
      ├── 评论管理（审核/驳回/删除）
      ├── 用户管理（查看/禁用）
      ├── 文件管理（浏览/删除）
      └── 数据统计（查看）
```

- **风格**：杂志风格（图文混排丰富）

- 🕐 **实时时间**：`2026年7月1日 16:05:52`（每秒更新）
- ⏱ **访问时长**：`您已访问 0小时12分35秒`（从进入页面开始计时）
- 🌐 **当前IP**：`183.6.122.45`
- 📍 **IP位置**：`广东广州`

## 6. 数据统计需求

### 6.1 统计指标
| 指标 | 说明 | 计算方式 |
|------|------|---------|
| 当前在线人数 | 当前正在访问网站的用户数 | 最近5分钟内有请求的唯一IP数 |
| 月访问总数 | 本月累计访问次数 | 按月统计请求记录 |
| 文章阅读量 | 每篇文章被查看次数 | 每次访问文章详情+1 |

## 7. 社交分享方案

### 7.1 分享形式
**卡片形式**（标题 + 描述 + 缩略图），非纯文本链接。

### 7.2 实现方式
1. **Open Graph 标签**：文章页 HTML head 输出 og:title/og:description/og:image
2. **Web Share API**：移动端原生分享
3. **海报生成**：使用 html2canvas 生成分享海报图

## 8. 管理员账号配置

### 8.1 配置化初始化
- 管理员账号信息从环境变量读取
- 如果数据库已存在该管理员账号，则跳过创建
- 支持自定义用户名、邮箱、密码

### 8.2 环境变量配置
```env
# 默认管理员账号配置
ADMIN_USERNAME=admin
ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD=admin123
```

### 8.3 实现逻辑
1. 启动时检查 `users` 表是否存在配置的用户名
2. 如果不存在，使用 bcrypt 加密密码后插入数据库
3. 如果已存在，跳过创建并输出提示信息
